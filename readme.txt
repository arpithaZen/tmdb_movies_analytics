# 🎬 TMDB Movie Database: Relational Data Engineering, SQL/Pandas Analytics & Streamlit App

## 📌 Project Overview
This end-to-end Data Science & Analytics capstone project transforms six normalized TMDB CSV datasets (`movies`, `genres`, `movie_genres`, `cast`, `crew`, and `movie_keywords`) into a clean relational SQLite database (`tmdb_movies.db`). It delivers comprehensive SQL and Pandas exploratory analyses, statistical visualizations, and an interactive three-page **Streamlit** web application for real-time catalog filtering, executive box office dashboards, and live SQL querying.

## 🗄️ Relational Database Schema (`tmdb_movies.db`)
The database follows a normalized star/snowflake-style relational structure centered around `movies`:

| Table Name | Primary / Foreign Keys | Description |
| :--- | :--- | :--- |
| **`movies`** | `movie_id` (PK) | Core metadata: title, language, release date, runtime, budget, revenue, popularity, rating, vote count, status, and overview. |
| **`genres`** | `genre_id` (PK) | Lookup table mapping unique genre IDs to readable genre names (e.g., Action, Drama). |
| **`movie_genres`** | `movie_id` (FK), `genre_id` (FK) | Junction table resolving the many-to-many relationship between movies and genres. |
| **`cast`** | `cast_row_id` (PK), `movie_id` (FK) | Top 10 billed actors per film along with character names and billing order (`0` = lead). |
| **`crew`** | `crew_row_id` (PK), `movie_id` (FK) | Key production credits (Directors, Writers, Producers) and their departments. |
| **`movie_keywords`** | `movie_id` (FK), `keyword_id` | Thematic tags and plot keywords associated with each film. |

## ⚙️ Project Workflow & Deliverables

### 1. `01_data_cleaning.ipynb` — Data Cleaning & SQLite Ingestion
* **Schema & Type Enforcement:** Parsed `release_date` into standard `YYYY-MM-DD` strings, cast all IDs and financial metrics to strict integer/float types, and standardized text strings.
* **Placeholder Handling:** Preserved `0` values in `budget` and `revenue` (which represent unknown financial figures in TMDB rather than free films) so downstream analyses can filter them transparently without skewing averages.
* **Referential Integrity:** Removed exact duplicates across all tables and pruned orphaned rows in child tables (`cast`, `crew`, `movie_genres`, `movie_keywords`) referencing non-existent `movie_id` records before loading into `tmdb_movies.db`.

### 2. `02_sql_analysis.ipynb` — SQL Analysis (10 Questions)
Executes 10 progressive SQL queries via `sqlite3`, covering multi-table `INNER`/`LEFT` joins (`movies ⋈ movie_genres ⋈ genres`), `GROUP_CONCAT` aggregations, `NULLIF()` zero-handling, `GROUP BY` with `HAVING` thresholds (e.g., directors with >3 films, genres with ≥20 films), and scalar subqueries comparing budgets and revenues against dataset averages.

### 3. `03_pandas_analysis.ipynb` — Pandas Analysis (10 Questions)
Performs in-depth programmatic analysis including unique entity counts, financial missingness evaluation, profit and Return on Investment (ROI) ranking (for budgets ≥ $1M), annual release volume trends, IQR-based runtime outlier detection, primary genre popularity comparisons, prolific actor rating averages, remake/duplicate title detection, and Z-score divergence between popularity and vote counts.

### 4. `04_visualizations.ipynb` — Visual Storytelling (10 Charts)
Built with **Matplotlib** and **Seaborn**, pairing every visualization with actionable insights:
* **Univariate:** Budget distribution (histogram/KDE), runtime spread (box plot), audience rating distribution (`vote_average`), and catalog volume per genre.
* **Bivariate:** Budget vs. box office revenue regression, popularity vs. vote count scatter, average rating by genre, and annual release counts (1980–present).
* **Multivariate:** Numeric feature correlation heatmap and a decade-by-genre average box office revenue heatmap.

### 5. `app.py` — Interactive Streamlit Web Application
Connected directly to `tmdb_movies.db` with a shared sidebar filter panel (Genre, Release Year Range, Minimum Rating, and `$0` Financial Exclusion toggle):
* **Page 1 (`Filters & Catalog`):** Real-time title search, live KPI summary metrics, and interactive filtered data table.
* **Page 2 (`Executive Dashboard`):** Dynamic Plotly scatter plots (Budget vs. Revenue sized by vote count) and annual release bar charts.
* **Page 3 (`SQL Query Explorer`):** Interactive SQL editor with preset analytical queries and custom read-only `SELECT` execution.

## 🚀 Setup & Execution Guide

### 1. Activate Virtual Environment & Install Dependencies
Open a terminal inside the `14-11-26TMDB` directory and run:
```bash
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# Install required libraries
python -m pip install -r requirements.txt
```

### 2. Generate the SQLite Database & Run Notebooks
Run the Jupyter Notebooks in numerical order:
1. Execute all cells in **`01_data_cleaning.ipynb`** to clean the CSVs and create **`tmdb_movies.db`**.
2. Execute **`02_sql_analysis.ipynb`**, **`03_pandas_analysis.ipynb`**, and **`04_visualizations.ipynb`** to generate all analytical outputs and charts.

### 3. Launch the Streamlit Application
```bash
python -m streamlit run app.py
```
Open the local URL displayed in your terminal (typically `http://localhost:8501`) to interact with the application.
